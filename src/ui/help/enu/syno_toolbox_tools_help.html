Tools

The Tools tab gives you a set of optional switches and one-off actions for your NAS. Each item below shows its current status directly under its name — enable a switch to turn that behavior on, and disable it to turn it back off.

Send WOL

Sends a Wake-on-LAN packet to wake a sleeping device on your local network.

  1. Choose a device from the dropdown list, which is populated automatically from devices discovered on your local network.
  2. Click Send WOL to wake it.
  3. Click Settings to open Hidden Devices, where you can tick devices you don't want cluttering the dropdown (e.g. devices that are always on) and click Save to hide them from the list.

Change Size Units to Binary

DSM normally displays file and storage sizes using decimal units (GB, MB, etc). Enabling this switches DSM's displayed size units to their binary equivalents (GiB, MiB, KiB, TiB) for your current language.

Cleanup Coredumps

Removes core dump files left behind by crashed processes, freeing up disk space. The status line shows whether any core dumps are currently present.

Enable Seagate Low Current Spinup

Enables low current spinup for compatible Seagate Exos or IronWolf Pro drives (16TB–38TB), which reduces the inrush current when the drive spins up. Only applies if a compatible drive is detected in your NAS.

Uninstall Active Insight

Removes Synology Active Insight if it's installed. The status line shows whether Active Insight is currently present on your NAS.

Check Connected to UPS Server

Periodically checks that your NAS is still connected to its configured UPS server, at the interval you choose from the Frequency dropdown.

DSM Configuration Backup and Export

Automatically backs up your DSM configuration on a schedule.

  1. Choose how often to back up from the Frequency dropdown.
  2. Set Target dir to where backups should be saved, using Browse… to pick a folder.
  3. Optionally tick Remote backup (and 2nd remote backup) to also copy backups to another NAS. Click Discover NAS… to find one on your network, or enter its Remote IP, port, Remote dir, Local user and Remote user manually.

Backup Synoboot Image

Backs up your NAS's synoboot image to the folder set in Backup destination path. Use Browse… to choose the destination.

Enable Sequential I/O for SSD Cache

Allows sequential I/O to be cached on the selected volume's SSD cache, at the block size (in KB) set in Sequential I/O (kb). Tick the volume(s) you want this applied to. Only available if your NAS has an SSD cache configured; the status line shows whether one was found.

Switch between SHR and RAID Group or Enable RAID F1

Changes the underlying RAID type of your storage pool between SHR and a standard RAID Group, using the dropdown to choose the target type. Tick RAID F1 to enable RAID F1 mode, which requires 3 or more 2.5" SSDs, or 3 or more NVMe drives, in the pool. The status line shows the pool's current RAID type and whether RAID F1 is enabled.

Restore RS3621 Fan Speed

Restores the expected fan speed behavior on RS3621-series models. Not needed on other models — the status line will indicate if the script isn't applicable to your NAS.

Disable Reset Button

Disables your NAS's physical reset button, to prevent DSM settings being reset by an accidental (or deliberate) button press. The status line shows whether the reset button is currently enabled or disabled.
