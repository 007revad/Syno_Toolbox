Tools Help

The Tools tab gives you a set of optional switches and one-off actions for your Synology. Each item below shows its current status below it. Enable and Save to turn that behavior on, and disable and Save to turn it back off.

Send WOL

Sends a Wake-on-LAN packet to wake a sleeping device on your local network.

  1. Choose a device from the dropdown list, which is populated automatically from devices discovered on your local network.
    • If you select a device and click Save the selected device will be pre-selected next time.
  2. Click Send WOL to wake the selected device.
  3. Click Settings to open Hidden Devices, where you can tick devices you don't want cluttering the dropdown and click Save to hide them from the list.
    • e.g. Devices that are always on or don't support WOL.

Change Size Units to Binary

DSM normally displays file and storage sizes using decimal units (GB, MB, etc). Enabling this switches DSM's displayed size units to their binary equivalents (GiB, MiB, KiB, TiB) for your current language.
The tool's status area shows the current DSM storage size units for your language.

Cleanup Coredumps

Removes core dump files left behind by crashed processes and packages, freeing up disk space.
The tool's status area shows whether any core dumps are currently present.

Enable Seagate Low Current Spinup

Enables low current spinup for compatible Seagate Exos or IronWolf Pro drives (16TB-38TB), which reduces the inrush current when the drive spins up.
The tool's status area shows the status of compatible drives or if no compatible drives were found.

Uninstall Active Insight

Uninstalls Synology Active Insight if it's installed. If enabled, when Syno Toolbox starts it will uninstall Active Insight after a DSM update has re-installed it.
The tool's status line shows whether Active Insight is currently installed.

Check Connected to UPS Server

Periodically checks that your NAS is still connected to its configured UPS server, at the interval you choose from the Frequency dropdown.

DSM Configuration Backup and Export

Automatically backs up your DSM configuration on a schedule.

  1. Choose how often to back up from the Frequency dropdown.
  2. Set Target dir to where backups should be saved, using Browse to pick a folder.
  3. Optionally tick Remote backup (and 2nd remote backup) to also copy backups to another NAS. Click Discover NAS to find one on your network, or enter its Remote IP, port, Remote dir, Local user and Remote user manually.

Backup Synoboot Image

Backs up your Synology's synoboot USB DOM image to the folder set in Backup destination path. Click Browse to choose the destination. If enabled it runs when the package starts and only backs up synoboot and it's partitions once for each DSM version.
The tool's status area shows if a backup exists for the current DSM version.

Backup MTD Image

Backs up Value and Junior model's MTD flash image to the folder set in Backup destination path. Click Browse to choose the destination. If enabled it runs when the package starts and only backs up the MTD and it's partitions once for each DSM version.
The tool's status area shows if a backup exists for the current DSM version.

Enable Sequential I/O for SSD Cache

Allows sequential I/O to be cached on the selected volume's SSD cache, at the block size (in KB) set in Sequential I/O (kb). Tick the volume(s) you want this applied to. Only available if your NAS has an SSD cache configured.
The tool's status line shows whether one was found.

Switch between SHR and RAID Group or Enable RAID F1

Allows you to create SHR storage pools on Synology models that don't give you the choice of SHR. Allows you to create RAID Group storage pools on Synology models that don't give you the choice of RAID Groups.

  • Both SHR and RAID Group cannot be enabled at the same time.
  • Whichever one is selected only changes which type of storage pool can be created in Storage Manager. Managing existing storage pools is not affected.
  • Enabling RAID F1 is independent of SHR or RAID Group.
  • RAID F1 requires 3 or more SSDs of the same type: SATA, SAS or NVMe.
The tool's status area shows the pool's current RAID type and whether RAID F1 is enabled.

Restore RS3621 Fan Speed

Restore RS3621xs+ and RS3621RPxs Quiet mode and Cool mode fan speeds back to how it was before DSM 7.3.2.
Not needed on other models or older DSM versions and the status line will indicate if the script isn't applicable to your model or DSM version.

Enable root SSH Login

Enable or disable logging in to SSH as root and setting the root password. The tool's status area shows if SSH root login is enabled and if SSH is enabled.

Disable Reset Button

Disables your Synology's physical reset button, to prevent DSM settings being reset by an accidental (or deliberate) button press. Also useful if the Synology's reset button is broken and causing random resets. Remember to re-enable it after getting the reset button replaced.
The tool's status line shows whether the reset button is currently enabled or disabled.
